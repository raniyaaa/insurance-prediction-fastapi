# FastAPI ML Model Serving

A small learning project to understand how to serve a machine learning model using FastAPI and connect it to a Streamlit frontend.

> **Note:** The machine learning model used here is a dummy model for learning purposes. It is not intended for real-world insurance prediction.

## Tech Stack

- Python
- Scikit-learn
- FastAPI
- Pydantic
- Streamlit
- Pandas

## Run Locally

### Start FastAPI

```bash
uvicorn app:app --reload
