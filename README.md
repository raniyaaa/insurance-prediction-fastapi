# FastAPI ML Model Serving

A learning project where I built a basic machine learning model to predict insurance premium categories and served it through a FastAPI API with a Streamlit frontend.

> **Note:** The machine learning model used here is a dummy model for learning purposes. It is not intended for real-world insurance prediction.

## Tech Stack

- Python
- Scikit-learn
- FastAPI
- Pydantic
- Streamlit
- Pandas

## Run Locally

### Start FastAPI

```bash
uvicorn app:app --reload
